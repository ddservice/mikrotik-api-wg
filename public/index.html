เลือก LAN / VLAN / Bridge Interface จากราวเตอร์จริง หรือระบุ IP Subnet เพื่อเจาะจงให้เจาะออกสาย WAN ที่ต้องการ

Interface ทราฟฟิกขาเข้า (Source Interface / Subnet) สาย WAN ขาออกที่ต้องการเจาะจง คำอธิบาย / หมายเหตุ ลบ

เลือก "รีเซ็ตเวลาใช้งานสะสม" หรือ "ลบและสร้างใหม่" ทุกครั้งที่ลูกค้าซื้อคูปอง/เติมเงินต่ออายุด้วย Username เดิม ไม่เช่นนั้นเวลาที่ใช้ไปก่อนหน้าจะสะสมค้างและชนกับ Uptime Limit ของแพ็กเกจใหม่ทันที ระบบเลือก "รีเซ็ตเวลาใช้งานสะสม" ให้อัตโนมัติ เนื่องจากตรวจพบว่าคุณแก้ไขค่า Uptime Limit — เปลี่ยนตัวเลือกด้านบนได้หากไม่ต้องการ

คืนค่า / สร้างบัญชี Hotspot เดิมกลับเข้า MikroTik

เพิ่มแพ็กเกจใหม่

ตัดการเชื่อมต่อที่ไม่มีทราฟฟิกค้างไว้นานเกินนี้ ช่วยล้างเซสชันค้าง (เช่น ห้องไฟดับ) ให้อัตโนมัติ

นับจากเวลาที่ห้องนั้นเริ่มต่อ (ไม่ใช่เวลาตายตัวของวัน) บังคับต่อ PPPoE ใหม่เป็นระยะเพื่อล้าง state สะสม

ตั้งค่า PPPoE Server บน MikroTik

ทำครั้งเดียวต่อไซต์งาน — กรอกข้อมูลแล้วกด "สร้างสคริปต์" จากนั้นคัดลอกไปวางใน WinBox → Terminal บน MikroTik ของไซต์นั้น (ถ้าใช้ VLAN แยกวงสำหรับห้องเช่า ต้องตั้งค่าฝั่ง Switch เองแยกต่างหาก — MikroTik API ตั้งค่าให้เฉพาะฝั่งราวเตอร์เท่านั้น)

เพิ่มผู้ใช้งานระบบใหม่

ปล่อยว่างไว้หากไม่ต้องการเปลี่ยนรหัสผ่านเดิม

เพิ่มไซต์งาน / เราท์เตอร์ใหม่

Username/Password คือบัญชี login เข้า RouterOS API ของราวเตอร์ตัวนี้ (คนละเรื่องกับ WireGuard) — ต้องกรอกตั้งแต่ครั้งแรก ไม่งั้น dashboard จะเชื่อมต่อราวเตอร์ไม่ได้เลยไม่ว่าจะใช้ WireGuard หรือ Direct IP ก็ตาม แก้ไขทีหลังได้เสมอ (ช่อง Password ตอนแก้ไข ปล่อยว่างไว้ได้ถ้าไม่ต้องการเปลี่ยนรหัสผ่านเดิม)
ขั้นตอนแนะนำสำหรับ WireGuard: (1) เลือก Connection Type = WireGuard และกรอก WireGuard IP + Port ด้านล่างนี้ก่อน (2) กดปุ่ม "สร้างสคริปต์ WireGuard" ท้ายฟอร์ม (จะดึงค่าที่กรอกไว้นี้ไปใช้อัตโนมัติ) (3) รันสคริปต์บนราวเตอร์ (4) ค่อยกลับมากด "บันทึกไซต์งาน" ที่นี่อีกครั้ง
ต้องไม่ซ้ำกับไซต์งานอื่นที่มีอยู่แล้ว
ถ้าใช้ WireGuard ควรตรงกับ "WireGuard IP" ด้านบน — ระบบจะเติมให้อัตโนมัติเมื่อเลือก Connection Type เป็น WireGuard
ปล่อยว่างไว้หากไม่ต้องการเปลี่ยนรหัสผ่านเดิม
เก็บประวัติเว็บไซต์ที่เข้าชม (DNS Visit History)
ปิดเพื่อหยุดดึงและบันทึกประวัติเว็บไซต์ของไซต์งานนี้ทั้งหมด (ลดภาระ router/web/database) — ไม่กระทบ log การเชื่อมต่อ Hotspot

ขั้นตอนที่ 1 คัดลอกสคริปต์ไปวางใน WinBox Terminal

คัดลอกสคริปต์ด้านล่างไปวางใน WinBox ➔ Terminal บน MikroTik ของคุณ — ถ้าตั้งค่า PUBLIC_APP_URL บนเซิร์ฟเวอร์ไว้แล้ว สคริปต์จะลงทะเบียน Public Key กลับมาให้อัตโนมัติ ไม่ต้อง copy กลับมาวางเอง (ขั้นตอนที่ 2 ด้านล่างเป็น fallback กรณีอัตโนมัติไม่สำเร็จ)

ขั้นตอนที่ 2 (สำรอง) อัปเดต MikroTik Public Key ไปยัง VPS ด้วยมือ

ใช้เฉพาะกรณีระบบลงทะเบียนอัตโนมัติไม่สำเร็จ — นำ Public Key ที่ได้จาก WinBox Terminal ในข้อ 1 มาวางในช่องนี้แล้วกดอัปเดต
